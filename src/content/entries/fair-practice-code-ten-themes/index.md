The Dutch edition of the Fair Practice Code (second print, June 2024) adds ten themes, each with a question. The English edition from 2019 doesn't have them yet, so we translated them for the second evening of Economic Cultures at DAE, printed next to the English code. The themes and questions are Kunsten '92's; the translation and the talk box are ours.
