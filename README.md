# bronvandoen.github.io

Working notes, workshop tools and prototypes from Bron van Doen, the social and service design practice in Eindhoven that includes a Situated Studio. For our own groups and workshops; the pages are kept out of search engines.

## Where things go

- `index.html`: the start page.
- `view.html`: a temporary reader for the working notes. Delete it once the real site exists; the posts stay as they are.
- `posts/<date>-<slug>/index.md`: one working note per folder, images next to it. Front matter: `title`, `date`, `summary`, `project` when it belongs to one, and `voices` (who speaks in it, e.g. `Gemma Medina and Minsung Wang`).
- `posts/posts.json`: the post folders, newest first.
- `tools/<project>/<tool>/index.html`: one workshop tool per folder, self-contained. Example: `tools/economic-cultures/hourly-rate/`.
- `prints/<project>/<print>/`: flat single images (flyers, posters, treated photos) as a page plus its exported image. Example: `prints/economic-cultures/blueprints-2026/`.
- `_inbox/`: raw material. Never published.
